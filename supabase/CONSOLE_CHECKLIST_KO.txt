역장님 앱 — Supabase 콘솔에서 직접 할 일 (코드로 대체 불가)
============================================================

1) 회원 탈퇴 SQL (탈퇴 버튼 쓸 때만 필수)
   - 대시보드 → SQL Editor → 새 쿼리
   - 프로젝트의 delete_own_account.sql 내용 전체 붙여넣기 → Run
   - 안 하면 앱에서 "탈퇴" 시 RPC 오류가 날 수 있음.

2) 웹(Chrome)에서 이메일 로그인·인증메일·비밀번호 재설정
   - 대시보드 → Authentication → URL Configuration
   - 아래 [복사용] 블록을 그대로 맞추면 됨 (다른 도메인에 웹만 둘 경우 Site URL·배포 웹 Redirect만 바꿈)

3) 역 데이터 번들(KRIC)
   - 이미 assets/stations_metro_kric.json 등은 저장소에 포함된 상태면 추가 작업 없음.
   - 엑셀을 다시 받았을 때만: dart run tool/kric_xlsx_to_stations.dart "경로.xlsx"

참고
